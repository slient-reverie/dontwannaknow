# 五个等级：从零基础到"能上线的全栈网站"

每个等级包含：**目标 / 学什么 / 练习什么 / 通关标准 / 预计时间**。
配合 `03_资源清单.md` 找对应资源，配合 `04_目标项目规划.md` 看每级对应的项目版本。

---

## ⭐ 等级一：网页基础 —— HTML + CSS（1~2 周）

**目标**：能独立写一个结构清晰、好看、在手机和电脑上都能正常显示的静态网页。

**学什么**
- HTML：常用标签、语义化（header/main/section/footer）、表单（input/button）、图片与链接
- CSS：选择器、盒模型、Flex 布局、Grid 布局、响应式（媒体查询 @media）、字体配色排版
- 工具：VS Code（安装 Live Server 插件）、Chrome 开发者工具（按 F12，会看、会改样式）

**练习什么**
1. 用纯 HTML/CSS 做一张"个人介绍页"（头像、自我介绍、兴趣爱好、联系方式、几张图）
2. 模仿一个你喜欢的网站首页布局（不用一模一样，练布局感觉）
3. 把 `05_第一个网页模板.html` 改造成你的第一个成品页

**通关标准**：不看教程，独立写出一个含 3 个板块、手机和电脑都能正常显示的静态网页。

---

## ⭐ 等级二：JavaScript 与网页交互（2~3 周）

**目标**：网页能"动起来"——能读取用户输入、计算、操作页面、保存数据。

**学什么**
- JS 语法：变量、数据类型、函数、数组、对象、循环、条件判断
- DOM 操作：选中元素、修改内容/样式、添加/删除元素
- 事件：点击、输入、按键
- localStorage：把数据存在浏览器里，关掉再打开还在
- fetch：请求接口（会用即可，深学在后面）
- 调试：console.log、浏览器开发者工具 Sources

**练习什么（这就是你目标网站的第一个原型！）**
- 做"热量计算器 v1"：输入食物名称和克数 → 算出热量
- 记录"今天吃了什么"，用 localStorage 保存
- 页面显示"今日总热量 vs 目标热量"，超出变红

**通关标准**：一个能输入、能计算、关掉浏览器再打开数据还在的交互页面。

---

## ⭐ 等级三：前端框架与工程化（3~4 周）

**目标**：用现代方式组织代码，页面变多、功能变复杂时，一个人也能维护。

**学什么**
- ES6+ 新语法：箭头函数、解构赋值、模板字符串、模块 import/export
- 工程化：npm 包管理器、Vite 脚手架（一条命令创建项目）、Git 版本管理（配合 GitHub）
- **Vue 3**：组件化（把页面拆成小组件）、响应式数据、v-if/v-for、事件与表单绑定
- Vue Router：多页面跳转；Pinia：全局状态管理（共享数据）
- 可选：Element Plus 组件库（现成的好看按钮、表格、表单）

**练习什么**
- 把"热量计算器 v1"重构成 Vue 应用"热量与账单管家 v2"
- 页面拆分：今日记录页 / 统计页 / 消费账本页 / 设置页
- 所有页面共用一套数据（Pinia 管理）

**通关标准**：一个用 Vue 组件搭建、多路由切换、数据共享、本地能跑的多页面应用。

---

## ⭐ 等级四：后端与数据库 —— 让网站"记住"每个人（3~4 周）

**目标**：数据存在服务器上，换设备也能看到自己的数据；支持注册登录。

**学什么**
- **Node.js + Express**：路由、中间件、RESTful API（GET/POST/PUT/DELETE）
- **数据库**：先 SQLite（零配置，练手友好），再学 MySQL（上线主流）
- **用户系统**：注册、登录、密码加密（bcrypt）、登录凭证（JWT）
- 环境变量（.env）、接口调试工具（Apifox / Postman）
- 前后端联调：前端 fetch 调用后端接口

**练习什么**
- 给"热量与账单管家"加后端，升级为 v3：
  - 注册 / 登录 / 退出
  - 食物记录、消费记录的增删改查（数据存数据库）
  - 月度热量统计、月度消费统计接口
  - 前端所有数据操作改为调用后端接口
- 用两台设备测试：登录后都能看到同一份数据

**通关标准**：登录后，在另一台电脑或手机上打开，也能看到自己的数据（说明数据真的存服务器了）。

---

## ⭐ 等级五：部署上线 —— 任何人的手机电脑都能访问（1~2 周 + 备案等待）

**目标**：输入网址，任何人的手机和电脑都能打开并正常使用。

**学什么**
- 响应式打磨：手机优先设计、各尺寸屏幕测试
- 性能基础：图片压缩、代码压缩、懒加载（了解即可）
- 安全基础：HTTPS 证书、密码加密、防 SQL 注入
- **部署**：先用免费的 Vercel / Netlify 把前端跑起来练手；正式用阿里云/腾讯云**轻量应用服务器** + 域名 + Nginx 反向代理
- 日志查看、简单排障（服务器上跑不动了怎么查）

**练习什么**
- 把 v3 项目正式部署上线（v4）
- 手机、电脑各完整测试一遍：注册 → 记饮食 → 看统计 → 记消费 → 看预算 → 退出重登

**通关标准**：输入你的网址，任何人的手机和电脑都能打开并正常使用。

> ⚠️ **重要提示**：如果服务器放在中国大陆，绑定域名必须办理 **ICP 备案**（免费，但通常需要 1~3 周审核）。建议提前准备：在等级三时就把域名注册好、开始备案流程，等学到等级五时备案刚好下来。
> 不想备案的替代方案：用 Vercel/Netlify 等境外免费托管（国内访问可能偏慢或不稳），适合练手和展示。

## 等级总览表

| 等级 | 名称 | 预计时间（每天2~3h） | 产出物 |
|---|---|---|---|
| 一 | HTML + CSS | 1~2 周 | 静态个人介绍页 |
| 二 | JavaScript | 2~3 周 | 热量计算器 v1 |
| 三 | Vue 3 + 工程化 | 3~4 周 | 热量与账单管家 v2 |
| 四 | Node.js + 数据库 | 3~4 周 | 全栈版 v3（登录+数据库） |
| 五 | 部署上线 | 1~2 周 | 正式上线 v4 |

**合计约 11~15 周（3~4 个月）**，脱产可压缩到 1.5~2 个月。
