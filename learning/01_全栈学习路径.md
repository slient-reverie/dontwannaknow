# 网页全栈开发学习路径（零基础 → 独立上线）

---

## 一、先建立全局概念：网页是怎么工作的？

想象你在手机/电脑上打开一个网站：

```
你的浏览器（前端）  --①请求-->  服务器（后端）  --②查-->  数据库
      ^                              |                    |
      |            ⑤渲染成界面     ③返回数据 <--②返回--   |
      └────────────────────────────────────────────────────┘
```

四个关键词：

| 概念 | 作用 | 例子 |
|---|---|---|
| **前端** | 用户看到、点击的一切 | 页面布局、按钮、图表 |
| **后端** | 处理数据和业务逻辑 | 登录验证、算热量、算预算 |
| **数据库** | 长期存放用户数据 | 你的食物记录、消费记录 |
| **部署** | 把代码放到永远在线的服务器 | 大家输入网址就能访问 |

你的目标网站 = 前端（记录界面、统计图表）+ 后端（存数据、算统计）+ 数据库（记住每个用户）+ 部署（任何设备可访问）。

## 二、学习路线总览

```
等级一  HTML + CSS        → 能做出"好看"的静态网页
等级二  JavaScript        → 网页能输入、计算、保存数据
等级三  Vue 3 + 工程化    → 用现代方式组织代码，页面越来越多也不乱
等级四  Node.js + 数据库  → 数据存服务器，支持注册登录，换设备不丢
等级五  部署上线          → 任何人的手机电脑都能打开使用
```

每个等级的详细内容见 `02_五个等级详解.md`。

---

## 三、技术选型（为什么这么选）

| 环节 | 选择 | 理由 |
|---|---|---|
| 前端框架 | **Vue 3**（备选 React） | 中文教程资源极多，对新手友好；学会一个，另一个很容易迁移 |
| 后端 | **Node.js + Express** | 和你已经学的 JavaScript 是同一门语言，不用再学一门新语言 |
| 数据库 | 先 SQLite 练手，后 MySQL | SQLite 零配置起步快，MySQL 是上线主流 |
| 部署 | 免费版 Vercel 练手 → 阿里云/腾讯云轻量服务器正式上线 | 国内正式上线需要国内服务器 + 域名 + ICP 备案 |
| 图表 | ECharts | 免费、中文文档、做热量/账单统计图很合适 |

> 不要纠结"Vue 还是 React"：**先选 Vue 3**。它是工具，不是信仰。

## 四、学习方法论（决定你能走多快）

1. **费曼学习法**：学完一个概念，用自己的话写下来或讲给别人听，讲不清楚就是没学会。
2. **边学边记**：维护自己的学习笔记（推荐用 GitHub 仓库或 Notion/语雀），每个知识点记 3 行：是什么 / 怎么用 / 示例代码。
3. **遇到报错怎么办（重要！）**：读报错信息 → 把报错复制去搜（必应/百度，英文报错搜英文）→ 看官方文档 → 还不行再问社区。**报错不是失败，是学习入口。**
4. **AI 辅助可以，但不要抄完就完**：AI（比如我）给的代码，要理解后自己敲一遍。
5. **固定节奏**：每天固定 1~3 小时，比周末突击 10 小时有效得多。
6. **每周做一个"交付"**：哪怕只是给页面加一个按钮，也要真的做出来，保持成就感。

## 五、时间表（每天 2~3 小时版本，共约 15 周）

| 周次 | 学习内容 | 对应等级 | 本周产出 |
|---|---|---|---|
| 第 1~2 周 | HTML + CSS + 开发工具 | 等级一 | 个人介绍静态网页 |
| 第 3~5 周 | JavaScript + DOM + localStorage | 等级二 | 热量计算器 v1（浏览器可用） |
| 第 6~9 周 | ES6 + npm + Vue 3（组件/路由/状态） | 等级三 | 热量与账单管家 v2（Vue 应用） |
| 第 10~13 周 | Node.js + Express + 数据库 + 登录 | 等级四 | 全栈版 v3（登录 + 数据库） |
| 第 14~15 周 | 部署 + 域名 + 备案 + 打磨 | 等级五 | 正式上线 v4，手机电脑可用 |

> 每周节奏示例：周一到周五每天学 1 节课 + 敲 1 小时代码；周末做一个练习项目或补课。

## 六、避坑指南（前人血泪）

- ❌ 收藏 100 个视频却一个都没看完 → ✅ 认准 1~2 套视频跟到底
- ❌ 跳过低谷期，直接学框架 → ✅ 基础（HTML/CSS/JS）必须扎实，否则后面全是坑
- ❌ 只抄不写，看完就忘 → ✅ 每个例子都自己敲一遍，改动点东西看效果
- ❌ 一上来就买几千块的课 → ✅ 免费资源足够你做到上线
- ❌ 纠结"最完美的工具" → ✅ 一个 VS Code 够用很久很久
- ❌ 卡住 3 小时死磕 → ✅ 卡 30 分钟就搜、就问、就跳过，明天再来
- ❌ 学后端时又纠结换语言 → ✅ 先 Node.js 一条路走完，之后学什么语言都快

## 七、什么叫"学完了"？

- 等级一到五全部通关（见 `02` 文档的通关标准）
- 你的网站上线，注册一个新账号，在手机和电脑上完整走一遍：记饮食 → 看热量统计 → 记消费 → 看预算 → 退出重登数据还在
- 遇到新需求（比如加个"食物收藏"功能），你能独立查资料实现它

达到这个状态，你就具备了**独立开发一个真正可用网页**的能力。
