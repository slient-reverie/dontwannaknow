# 目标项目：《大学生饮食热量与财务管理》网站规划

> 这是你从等级一学到等级五的**贯穿始终的项目**。每学一个等级，就给它加一块功能，最后它就是你的第一个真正作品。

---

## 一、一句话定义

一个让大学生**记录"吃了什么、花了多少钱"**，并自动统计**热量摄入和财务预算**的网页应用，手机和电脑打开即用。

## 二、核心功能清单（MVP，第一版上线版）

**用户系统**
- 注册 / 登录 / 退出登录
- 个人设置（每日热量目标、月度预算、个人信息）

**热量管理**
- 记录每餐：食物名称、克数、热量（支持自建"常用食物库"）
- 每日统计：今日摄入总热量 vs 目标热量（进度条）
- 趋势图表：按周 / 按月查看热量变化（折线图）

**财务管理**
- 记录每笔消费：金额、分类（餐饮/学习/娱乐/交通/其他）、备注
- 月度预算设置与超支提醒
- 分类统计：本月各分类占比（饼图）

**通用**
- 数据存服务器，换设备不丢
- 响应式设计：手机和电脑都好用

## 三、技术选型（与学习路径一一对应）

| 环节 | 选择 | 说明 |
|---|---|---|
| 前端 | HTML + CSS + JS → **Vue 3 + Vite** | 可选 Element Plus 组件库、Pinia 状态管理 |
| 图表 | **ECharts** | 免费、中文文档：https://echarts.apache.org/zh/index.html |
| 后端 | **Node.js + Express** | 与前端同语言，入门最快 |
| 数据库 | 开发期 **SQLite** → 上线 **MySQL** | SQLite 零配置起步；MySQL 上线主流 |
| 认证 | JWT + bcrypt | 登录凭证 + 密码加密 |
| 部署 | Vercel 练手 → **阿里云/腾讯云轻量服务器 + Nginx + 域名 + HTTPS** | 大陆服务器需 ICP 备案 |

## 四、按等级推进的项目版本（和 `02_五个等级详解.md` 一一对应）

| 等级 | 版本 | 这个版本是什么 | 有哪些功能 |
|---|---|---|---|
| 一 | **v0 静态页** | 一个好看的"热量与账单管家"首页 | 介绍页 + 静态界面草图，好看、响应式 |
| 二 | **v1 热量计算器** | 浏览器里能用的单页工具 | 输入食物算热量、今日记录、localStorage 保存 |
| 三 | **v2 组件化应用** | Vue 多页面 SPA | 记录/统计/账本/设置 四页，数据共享，图表初现 |
| 四 | **v3 全栈版** | 登录 + 数据库 | 注册登录、所有数据存数据库、接口化、换设备可用 |
| 五 | **v4 上线版** | 正式部署 | 域名 + HTTPS + 备案，手机电脑完整可用 |

## 六、学习时的落地节奏（每周做一点）

- **第 1~2 周（等级一）**：做出 v0 首页，先做到"好看"。
- **第 3~5 周（等级二）**：把 v0 首页加上"热量计算器"交互，变成 v1。
- **第 6~9 周（等级三）**：用 Vue 重构为 v2，四个页面 + 图表。
- **第 10~13 周（等级四）**：加后端和数据库，变成 v3，注册登录。
- **第 14~15 周（等级五）**：部署上线，变成 v4。

> 关键心态：**v0 很丑没关系，v1 只有三个按钮也没关系**。每一版都比上一版多一块功能，这就是"独立做出第一个网站"的过程。

## 七、后续升级方向（MVP 做完以后，可选）

- 接入食物营养数据库（按食物名自动查热量）
- 数据导出 Excel / 生成周报
- 多端同步、消息提醒（超支提醒、热量超限提醒）
- 社交：和朋友比步数一样比"饮食健康分"（可选）
