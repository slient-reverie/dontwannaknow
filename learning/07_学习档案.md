## 📏 教学规则（我定的，AI 必须遵守）

### A. 讲解规则
1. **一次只讲一个概念**，不要一口气塞一堆
2. 讲完必须给练习或动手任务
3. **答错不急给答案**：先给提示；**错两次之后**才给正确答案
4. 我说「**我要提示**」= 给提示；说「**直接告诉我**」= 直接给答案
5. 遇到技术问题，**先查 `06_实战踩坑笔记.md`**，再看当前代码

### B. 大作业规则（2026-10-27 新增，重点）
1. **少手写语法**，但**不许当黑箱**：必须"看得懂 + 改得动"
2. 每个作业都要交：需求拆解（用自己的话）+ 代码 + **理解三问**答卷
3. 验收时我会做**改动测试**：临时要求改一处功能，你独立完成
4. **允许 AI 生成代码，但禁止**：直接复制别人/demo 的整份项目当作业、把需求丢给 AI 就不管了
5. **卡住 30 分钟规则**：自己看报错/查文档/搜索，卡满 30 分钟再来问我
6. **模板类代码可以复制粘贴**（如 HTML 骨架、配置文件样板）；**核心逻辑必须自己写或自己改**

## 🧰 常用命令速查

**终端基础（Git Bash / macOS 通用）**
```bash
pwd        # 我在哪个路径
ls         # 这里有什么
cd 目录    # 进入目录     cd ..  回上一级     cd ~  回家目录
mkdir 名字 # 建目录
touch 名字 # 建空文件
cat 文件   # 看文件内容
rm 文件    # 删文件（删前先 pwd + ls）
```

**网络排查三件套（2.3 学的）**
```bash
ping 域名        # 通不通 + 解析出的 IP
nslookup 域名    # 域名 → IP（DNS 查询）
curl -I 网址     # 只看响应头（状态码 / 跳转）
```

**保存进度到 GitHub（三连）**
```bash
git add -A
git commit -m "写清楚今天做了什么"
git push
```

**在项目里跑起来（以后用到）**
```bash
npm install      # 装依赖
npm run dev      # 启动开发服务器
```
